# 纪念日倒计时

生日、结婚纪念日、入职多少年——写下几个日期，剩下的交给桌宠数着。

## 它做什么

| 落在哪 | 什么时候 | 长什么样 |
| --- | --- | --- |
| 宠物头顶（`pet.badge`） | 一直在（最近的那个进了「提前几天」的窗口才占位置） | `母亲节 还有 8 天`；当天是 `今天 母亲节` |
| 一句气泡（`bubble.say`） | **当天**，一天只一次 | `今天是母亲节，别忘了。` |
| 宠物旁边的卡片（浮层面，280×132） | 当天说完那句之后一分钟，自动摊开一次 | 最近三条：`名称 · 还有 N 天` |
| 控制中心的插件页（`workshop`） | 用户打开时 | 完整清单，加 / 删 / 空状态 |

徽标、气泡、卡片这三样都由**桌宠那边的常驻帧**推：它才有时钟，也才在"用户没看着"的时候还在。
`plugin.call` 就是撑起这个常驻帧的那项授权——**撤销它之后头顶就不再更新**（卡片与插件页照旧）。

### 几个刻意的选择

- **2 月 29 日只在闰年出现。** 平年的 2 月 29 日**当年不出现**，下一次是下一个闰年——从
  2027-02-28 看，下一次是 2028-02-29，还剩 366 天。另一种常见做法是折算到 3 月 1 日，本插件
  **不**这么做：2 月 29 日出生的人在平年既然没有那个日子，就不该被挪到别人的节日上。
- **日期一律按本机日历的整天差算。** 两个日期都先归一到**本地 00:00** 再相减，最后四舍五入：
  这样夏令时那两天（23 / 25 小时）也不会把"还有几天"算错一位。实现在 `lib/dates.js`，是纯函数。
- **12 月 31 日 → 1 月 1 日是 1 天。** 跨年只是年份变了，日历上没有跳过任何一天。
- **徽标不占别人的位置。** 只有"最近的那一个"进了「提前几天」（默认 30）的窗口才挂字，更远的
  不占头顶；改成"全部条数"就显示 `纪念日 3 个`。文字上限 16 字（宿主的硬上限），名称超了按
  **码点**截断成省略号。
- **当天只弹一次。** 记在 `anniversary/seen`（当天那句说完就记，跨重启也认）——不然重启一次
  就再弹一次。
- **卡片只在当天摊开一次**，而且是那句气泡之后一分钟：气泡与浮层面共用宠物旁边那个位置，同一
  时刻只能有一个。平时它不抢那个位置，头顶的徽标一直在。

## 设置（宿主绘制的设置表单）

| 键 | 类型 | 默认 | 意思 |
| --- | --- | --- | --- |
| `sayOnDay` | bool | `true` | 当天让桌宠说一句 |
| `badgeMode` | select | `nearest` | 徽标显示「最近的那一个」还是「全部条数」 |
| `advanceDays` | number | `30` | 提前几天开始占徽标（0 = 只有当天） |

清单本身存在插件自己的私有目录里（`anniversary/list`），只有这个插件读得到。

## 给别的插件：`plugin.call` 的 `next`

```jsonc
// plugin.call { target: "com.shixiansi.plugin-anniversary", method: "next", payload: {} }
{
  "items": [
    { "name": "母亲节", "date": "2026-05-10", "days": 8, "remaining": 8,
      "yearly": true, "text": "母亲节 · 还有 8 天" }
  ],
  "nearest": { "name": "母亲节", "date": "2026-05-10", "days": 8, "remaining": 8,
               "yearly": true, "text": "母亲节 · 还有 8 天" },
  "count": 1,
  "today": "2026-05-02",
  "updatedAt": 1770000000000
}
```

- `items` 是按"值得看的顺序"排的：还没到的在前（最近的在最前），已经过去的排在后面（刚过去的
  在那些的最前）。`nearest` 是**下一个还没过去的**，一个都没有时是 `null`。
- `date` 是**这一次**落在哪一天（每年重复的条目给的是下一次，不是当初写的那一年）。
- `days` 与 `remaining` 是同一个数（0 = 今天，负数 = 已经过去）；`text` 是给人看的那半句。
- 未知方法回一条说得清的中文 error（`ok:false`），不会沉默到超时。
- 这个插件只 `serves: ["next"]`；它**不**调用别人（没有 `callTargets`）。

## 权限（只申请用得到的五项）

| 权限 | 为什么 |
| --- | --- |
| `storage` | 清单与「当天说过」的记号 |
| `plugin.config` | 上面那三个设置项 |
| `pet.surface` | 头顶那行字（`pet.badge` 借的就是它）与那块卡片 |
| `pet.bubble` | 当天说那一句 |
| `plugin.call` | 被别人问 `next`，同时撑起常驻帧 |

没有网络、没有 secret、没有 `hostWhitelist`：这个插件**一个字节都不往外发**。

## 文件

```
manifest.json     清单
panel.html        入口：卡片 + 插件页（一个文档三种面孔，由 init.surface 决定）
app.js            握手、分派、常驻帧的时钟、plugin.call 的 next
lib/dates.js      纯日期函数（本地整天差、闰年 2/29、下一次落在哪天）
lib/agenda.js     纯视图模型（清单归一化、排序、徽标与气泡的文案）
lib/core.js       宿主桥、DOM 句柄、config/storage 包装
lib/card.js       浮层面那张卡片
lib/workshop.js   控制中心那一整页
style.css         自带调色板（声明了浮层面，所以不引 ui.css）
```
