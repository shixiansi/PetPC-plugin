    别的插件怎么用它

    申请了 plugin.call 的插件可以在自己 manifest 的 callTargets 里点名 com.shixiansi.plugin-convert-kit/convert，然后把问题发过来： 

    {"category":"length","from":"m","to":"ft","value":12.5}
→ {"category":"length","from":"m","to":"ft","input":12.5,
   "value":41.01049868766404,"text":"41.01","unit":"ft",
   "expression":"12.5 m = 41.01 ft"}

    分类写 length / weight / volume / temperature / speed / timezone / base / currency，也可以写中文名。 单位不认识时会回一条点名的中文 error（例如「不认识单位“市斤”」），不会静默按 1:1 换算。 完整的分字段说明在插件的 README 里。
